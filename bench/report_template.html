Scaling with processing units

Median MB/s of 2 runs at a 32 KiB chunk. For each source, every setting produced a byte-identical ZIP.

How it was tested: 13 sources (one file and the whole folder for each size, plus all sets together) × 39 options (ZIP on CPU, GPU and ALL at 2/4/8/16/32/64/128/256/512 KiB chunks, and .ocpk with XPRESS, or with DEFLATE on GPU, ALL and CPU, at 1/4/16 MiB blocks), 3 runs each. Runs 2 and 3 pre-read sources under 16 GiB into the file cache and change the order of the options. Added later with 1 run each: ZIP at 1 KiB and 1 MiB chunks, .ocpk at 2/8/32/64 MiB blocks, and the 4 × 10 GiB set, which ran only these new options (its other cells say “not run”). Run 1 verified every archive: each CPU ZIP was fully decompressed and each .ocpk passed oclzip test (for the new options only on sources up to 16 GiB, to save time), and each archive’s CRC was compared across CPU, GPU and ALL on every source.
